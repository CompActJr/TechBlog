Controle de Versão com Git e GitHub

Atualizado em Agosto de 2026 | Por: Equipe de Capacitação da CompActJr

Apresentação

O Git é um sistema de controle de versão distribuído amplamente utilizado no desenvolvimento de software. Ele permite que múltiplos desenvolvedores colaborem em um mesmo projeto de forma segura, mantendo o histórico de alterações rastreável. O GitHub é uma plataforma de hospedagem baseada em nuvem que facilita o gerenciamento desse histórico e o trabalho cooperativo.

O que você vai aprender

  • Configuração inicial do Git (user.name, user.email, SSH keys)
  • Ciclo de vida de arquivos (git status, add, commit)
  • Sincronização remota (git push, pull, clone, fetch)
  • Ramificação (git branch, checkout, switch, merge)
  • Resolução de conflitos de mesclagem

Orientações para Estudo

Crie um repositório de testes no GitHub e execute todos os comandos básicos localmente no seu terminal. Errar e resolver conflitos no início é a melhor forma de fixar o fluxo de branches do Git.
