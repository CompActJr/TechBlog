Fundamentos de Web: HTML5 e CSS3

Atualizado em Agosto de 2026 | Por: Equipe de Capacitação da CompActJr

Apresentação

HTML5 e CSS3 são a espinha dorsal de qualquer site na internet. O HTML (HyperText Markup Language) serve para dar estrutura e significado semântico ao conteúdo da página, enquanto o CSS (Cascading Style Sheets) gerencia o estilo visual, layout, cores, fontes e responsividade para diferentes tamanhos de tela.

O que você vai aprender

  • Tags semânticas do HTML5 (header, nav, main, section, article, footer, etc.)
  • Estruturação e organização de elementos na tela
  • Estilização de layouts com Flexbox e CSS Grid
  • Variáveis CSS e paletas de cores centralizadas
  • Criação de designs responsivos com Media Queries

Orientações para Estudo

Recomendamos seguir os links de cursos e documentações ao lado. Comece entendendo a semântica do HTML para só então aplicar estilos complexos. O segredo da estilização é praticar recriando layouts simples.
