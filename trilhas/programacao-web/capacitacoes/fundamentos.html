1. História da Web

A web (World Wide Web) é um sistema de informação baseado em hipertexto — ou seja, documentos ligados entre si por links. Ela nasceu com um objetivo claro: permitir que pessoas compartilhassem e acessassem informações de qualquer lugar do mundo, de forma simples e aberta. A web roda sobre a internet (a rede física de computadores), mas é apenas uma das aplicações que usam essa rede.

Linha do tempo da criação e evolução

  • 1969
    Surge a ARPANET, a rede precursora da internet, criada por pesquisadores nos Estados Unidos.
  • 1989
    O britânico Tim Berners-Lee, trabalhando no CERN (Suíça), propõe o sistema que viraria a World Wide Web para compartilhar documentos científicos.
  • 1990
    Berners-Lee cria o primeiro navegador e o primeiro servidor web, além de escrever o HTML — a linguagem de marcação que estrutura as páginas.
  • 1991
    O primeiro site da história (info.cern.ch) entra no ar explicando o que era a web e como criar páginas.
  • 1993
    O navegador Mosaic populariza a web ao exibir imagens dentro das páginas, abrindo o caminho para o grande público.
  • 1995
    JavaScript é criado por Brendan Eich em apenas 10 dias, dentro do navegador Netscape, para dar interatividade às páginas.
  • 1996
    O CSS (Cascading Style Sheets) é padronizado para separar a estrutura do conteúdo da sua apresentação visual.
  • 2014
    O HTML5 se torna recomendação oficial, adicionando tags semânticas, áudio/vídeo nativo e mais recursos para aplicações modernas.
  • Hoje
    A web evoluiu de páginas estáticas para uma plataforma completa: aplicativos, comércio, educação, jogos e muito mais, tudo dentro do navegador.
Ponto chave: HTML estrutura, CSS estiliza e JavaScript dá comportamento. Atrás delas está a web: aberta, gratuita e universal. Entender o "porquê" ajuda a entender o "como".

2. HTML — A Estrutura da Página

O que é HTML?

HTML (HyperText Markup Language) é a linguagem de marcação usada para estruturar o conteúdo da web. Ele não é uma linguagem de programação: ele não executa lógica, apenas descreve o que cada parte da página representa — títulos, parágrafos, imagens, links, listas, tabelas e formulários. Essa descrição é interpretada pelo navegador, que a transforma em elementos visuais.

Como funciona

O navegador lê o arquivo HTML de cima para baixo e monta uma estrutura em árvore chamada DOM (Document Object Model). Cada pedaço de conteúdo é delimitado por tags — palavras-chave entre colchetes angulares. A maioria das tags possui abertura e fechamento:

<tag atributo="valor">conteúdo</tag>

Existem também tags vazias (auto-fecháveis), que não possuem conteúdo interno, como <img>, <br> e <input>. Os atributos fornecem informações extras, como o caminho de uma imagem (src) ou o texto alternativo (alt).

Estrutura básica de um documento

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <title>Título da página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
  </body>
</html>
  • <!DOCTYPE html> — informa ao navegador que o documento usa HTML5.
  • <head> — metadados (não aparece na tela): charset, título, estilos e links.
  • <body> — todo o conteúdo visível da página.

3. CSS — O Estilo e o Layout

O que é CSS?

CSS (Cascading Style Sheets) é a linguagem de estilo da web. Enquanto o HTML cuida da estrutura, o CSS cuida da aparência: cores, fontes, espaçamentos, tamanhos, posicionamento e responsividade. Ele separou o conteúdo da apresentação, tornando as páginas flexíveis e fáceis de manter.

Como funciona

O CSS é formado por regras, compostas por um seletor (quem será estilizado) e um bloco de declarações (propriedade: valor). O termo em cascata significa que, havendo conflitos, a regra mais específica ou a última declarada ganha.

seletor {
  propriedade: valor;
  propriedade2: valor2;
}

Exemplo real: estilizar todos os parágrafos com cor azul.

p {
  color: #2837a0;
  font-size: 18px;
}

Principais conceitos

Box Model

Todo elemento é uma caixa com conteúdo, padding (espaço interno), border (borda) e margin (espaço externo).

Display

Controla como o elemento se comporta: block, inline, flex, grid, etc.

Cores e fontes

color, background, font-family, font-size, font-weight.

Responsividade

Com @media e unidades relativas (rem, %, vw) o layout se adapta a qualquer tela.

Exemplo prático e editável

O exemplo mostra cores, fontes, centralização e o efeito hover no botão aplicados com CSS.

4. JavaScript — O primeiro toque de programação

O que é JavaScript?

JavaScript (JS) é uma linguagem de programação interpretada pelo navegador. Diferente do HTML e do CSS — que apenas marcam e estilizam — o JavaScript executa lógica: reage a cliques, valida formulários, busca dados, anima elementos e constrói aplicações inteiras. É a camada de comportamento da página.

Como funciona

  • É escrito dentro de <script>...</script> ou em arquivos .js separados.
  • Interage com a página através do objeto document (o DOM).
  • Executa de forma assíncrona e orientada a eventos (clicou, mudou, carregou...).
  • Usa variáveis (let, const), funções, estruturas de decisão e repetição como qualquer linguagem de programação.

const ano = 2026;

  return "Olá, " + nome + "!";

Exemplo interativo e editável

Este contador é movido a JavaScript: o script "ouve" o clique no botão, incrementa uma variável e atualiza o texto da página.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>JavaScript na prática</title>
  <style>
    body {
      font-family: sans-serif;
      padding: 2rem;
      text-align: center;
    }
    button { padding: 12px 24px; font-size: 18px; font-weight: 700; border: none; border-radius: 8px;
             background: #9628a5; color: #fff; cursor: pointer; }
    #saida { font-size: 20px; margin-top: 1rem; color: #1c314c; }
  </style>
</head>
<body>
  <h1>Contador em JavaScript</h1>
  <button id="botao">Clique em mim</button>
  <p id="saida">Você clicou 0 vezes.</p>

  <script>
    let contador = 0;
    const botao = document.getElementById("botao");
    const saida = document.getElementById("saida");

    botao.addEventListener("click", () => {
      contador = contador + 1;
      saida.textContent = "Você clicou " + contador + " vezes.";
    });
  </script>
</body>
</html>
